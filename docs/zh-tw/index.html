在 Windows 電腦上控制 Sony WH-1000XM4、XM5、XM6 耳機

用電腦控制 XM5：直接在電腦上切換降噪和環境音、調整環境音強度、設定等化器（EQ）、查看電量。Sony 的 Headphones Connect / Sound Connect 只有手機版，XM Control 把這些設定搬到 Windows 上，不用再拿手機。

手機 App 裡常用的設定，電腦上都能調

XM Control 透過你聽音樂用的同一條藍牙連線和耳機溝通，不用重新配對，也不經過任何雲端服務。

降噪與環境音

降噪、環境音、關閉一鍵切換，環境音強度 1–20，以及「專注於人聲」。

等化器（EQ）

選預設，或自己調每個頻段：5 段加 Clear Bass，WH-1000XM6 則是 10 段等化器。

電量

視窗裡直接顯示電量與充電狀態，滑鼠移到右下角圖示上也看得到。

常駐系統匣

關掉視窗後會留在右下角時鐘旁，按右鍵就能切換降噪模式。

頭部追蹤

用 WH-1000XM5、XM6 內建的動作感測器，即時顯示一顆跟著你轉頭的 3D 頭像。

安全設計

只會送出白名單內的少數指令，絕不可能送出韌體更新、恢復原廠、關機或配對相關的指令。

一分鐘裝好

不用 Python、不用註冊帳號，也不需要系統管理員權限。

  1. 配對耳機

    在 Windows 設定 →「藍牙與裝置」配對，跟平常聽音樂一樣。

  2. 下載 XM Control

    到最新版本頁面， 下載 setup.exe 安裝檔，或免安裝的 .zip。

  3. 打開就能用

    執行 XM Control，它會找到耳機並顯示目前的設定。

程式目前沒有數位簽章，Windows 可能顯示「Windows 已保護您的電腦」，請按「其他資訊 → 仍要執行」。

常見問題

Sony Headphones Connect 有電腦版嗎？

沒有。Sony 的 Headphones Connect 和後來的 Sound Connect 都只有 Android、iOS 版本。XM Control 是非官方的免費 Windows 軟體，讓你在電腦上調整最常用的設定。

XM5 可以用電腦控制嗎？

可以。Sony 官方沒有電腦版 App，但 XM Control 可以在 Windows 電腦上控制 XM5（WH-1000XM5）：切換降噪、環境音， 調整等化器，查看電量。XM4、XM6 也適用。

可以用筆電切換 WH-1000XM5 的降噪嗎？

可以。耳機用藍牙連著筆電時，打開 XM Control 就能切換降噪、環境音或關閉，播音樂、講電話時也能切。

WH-1000XM6、WH-1000XM4 可以用嗎？

WH-1000XM6 有使用者回報可以使用，包括 10 段等化器和自動調整環境音強度。WH-1000XM4 依照公開的協定資料實作， 但還沒有在實機上測試過。

會不會弄壞耳機？

XM Control 只能送出讀取和修改這些設定需要的指令，每一則訊息都會先比對白名單，所以不可能送出韌體更新、恢復原廠、 關機或配對相關的指令。原始碼公開在 GitHub 上。

需要安裝 Python 或手機 App 嗎？

都不用，下載的檔案已經包含一切。手機 App 可以留著，只是不要兩邊同時操作。

有指令列版本嗎？

有。程式附帶 sonyxm.exe，例如 sonyxm nc on、sonyxm ambient 12、 sonyxm battery。

XM Control 是非官方專案，與 Sony 無關。Sony 與 WH-1000XM 是 Sony Group Corporation 的商標。
