Control Sony **WH-1000XM4 / XM5 / XM6** headphones from Windows: noise cancelling, ambient sound, equalizer, battery and head tracking, without the phone app. No Python needed.

**Download one of these** (below, under Assets):

- `XM-Control-…-setup.exe`: installer (no administrator rights needed), with Start menu and optional desktop shortcut.
- `XM-Control-…-windows.zip`: portable. Unzip and run `XM Control.exe`.

Windows may warn that the app is from an unknown publisher (it is not code-signed). Click **More info → Run anyway**.

Tested on the WH-1000XM5. Support for the WH-1000XM4 and XM6 follows other open-source projects and has **not been tested on real headphones yet**: please open an issue with what works and what does not.

---

在 Windows 上控制 Sony **WH-1000XM4 / XM5 / XM6** 耳機：降噪、環境音、等化器、電量、頭部追蹤，不需要手機 App，也不需要安裝 Python。

- `XM-Control-…-setup.exe`：安裝檔（不需要系統管理員權限），會建立開始功能表捷徑，可選擇建立桌面捷徑。
- `XM-Control-…-windows.zip`：免安裝版，解壓縮後執行 `XM Control.exe`。

程式沒有數位簽章，Windows 可能會跳出「Windows 已保護您的電腦」，請按「**其他資訊 → 仍要執行**」。

已在 WH-1000XM5 實機測試；WH-1000XM4 與 XM6 依照其他開源專案的資料實作，**尚未實機測試**，歡迎開 issue 回報結果。
